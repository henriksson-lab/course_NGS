# NGS library preparation — course materials

Quarto site for a course on next-generation sequencing (NGS) library preparation.
Scaffold copied from the 5MO115 *Bioinformatics and genome analysis* course.

## Layout

The framework is copied from the *Quantitative biology and integrative omics* course
(`quantbio-3MB00A`): a Quarto website rendered into `docs/`, with **one folder per unit** at
the repository root.

- `index.qmd` — landing page
- `<unit>/lec.qmd` — the slide deck (revealjs); a unit may have more, e.g. `lec-platforms.qmd`
- `<unit>/readings.qmd` — the reading list, with DOIs
- `<unit>/exercise.qmd` — exercises with collapsible Hint / Solution callouts
- `<unit>/figNN-*.svg` — that unit's figures, generated by `tools/make_figures.py`
- `_quarto.yml` — **the order of the course lives here**, in the sidebar, not in filenames
- `theme.scss` — slide theme · `styles.css` — website sidebar styling
- `CURRICULUM.md`, `AUDIENCE.md`, `planning/` — teacher-only, not published
- `tools/check_course.py` — enforces the material rules

## Build

```
make          # check, then render the site into docs/
make render   # render only
make preview  # live preview, re-rendering as you edit
make check    # enforce the material rules (slide count, picture ratio, no code)
make figs     # regenerate the conceptual SVG figures
make clean    # remove docs/ and .quarto/
```

No HTML is committed. `.github/workflows/pages.yml` renders the site on every push
to `main` and publishes it to
[henriksson-lab.github.io/course_NGS](https://henriksson-lab.github.io/course_NGS/).
The workflow runs `make check` and verifies the checked-in figures still match
`tools/make_figures.py` before it publishes, so a broken deck never reaches the site.
Only `_site/` is published: `CURRICULUM.md`, `planning/` and `oldpres/` stay out of it.

## Slides

The house YAML for a deck, as in `quantbio-3MB00A`:

```
---
title: "..."
subtitle: "Part · NGS library preparation"
author: "Johan Henriksson"
format:
  revealjs:
    theme: [simple, ../theme.scss]
    slide-number: c/t
    width: 1280
    height: 720
    transition: none
    history: false
    highlight-style: github
    code-overflow: wrap
    code-line-numbers: false
    incremental: false
    chalkboard: false
    menu: true
    html-math-method: katex
---
```

The navigation arrows come from the plain top-level `controls` keys in `_quarto.yml`,
which HTML pages ignore. `history: false` keeps a deck to one browser-history entry
instead of one per slide.

Save to PDF from the browser: print, landscape, no margins, background graphics on.

## Rules for the material

- No programming. Exercises are design questions, quizzes and enzyme-selection tasks.
- A deck is about 30 slides at most — a guideline the checker reports on rather than
  enforces — and at least half of them carry a picture, which is enforced — always alongside
  text, never a picture on its own slide. `make check` enforces this.
- All examples are framed in human biology.
- Every method named cites its original paper; protocols link to their
  [NGS 101](https://henriksson-lab.github.io/NGS_101/) page.
- Figures are generated as SVG by `tools/make_figures.py`, which asserts that every drawn
  duplex actually base-pairs.
